# QR-code-recognition

一个 Chrome 浏览器插件：点击插件图标或使用快捷键即可截图当前页面，自动识别截图中的二维码，并展示解析内容；若识别结果是网址，还可直接点击跳转。

## 功能

- 点击扩展图标即可截图并识别当前可见页面
- 支持快捷键触发截图识别（默认 `Ctrl+Shift+Q` / `Command+Shift+Q`）
- 自动解析截图中的二维码文本内容
- 当识别结果为网址时，提供可点击跳转入口
- 展示来源页面、页面地址和截图时间

## 安装

1. 打开 Chrome，进入 `chrome://extensions`
2. 开启右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目根目录（解压后的扩展程序文件夹）

## 使用

1. 打开包含二维码的网页，并确保二维码位于当前可见区域
2. 通过以下任一方式触发识别：
   - 点击浏览器工具栏中的插件图标
   - 使用快捷键 `Ctrl+Shift+Q`（macOS 为 `Command+Shift+Q`）
3. 插件会自动截图当前页面并打开结果页
4. 若识别成功，结果页会展示二维码内容；若内容是网址，可直接点击打开

## 快捷键修改

如需自定义快捷键，可打开 `chrome://extensions/shortcuts` 进行修改。
