# QR-code-recognition

一个 Chrome 浏览器插件：点击插件图标、使用快捷键，或右键网页中的图片即可识别 QR 码，并展示解析内容；若识别结果是网址，还可直接点击跳转。

## 功能

- 点击扩展图标即可截图并识别当前可见页面
- 支持快捷键触发截图识别（默认 `Ctrl+Shift+Q` / `Command+Shift+Q`）
- 支持右键网页中的图片并直接扫码
- 自动解析截图或所选图片中的二维码文本内容
- 当识别结果为网址时，提供可点击跳转入口
- 展示识别来源、来源页面、页面地址和触发时间

## 安装

1. 打开 Chrome，进入 `chrome://extensions`
2. 开启右上角“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择本项目根目录（解压后的扩展程序文件夹）

## 使用

1. 打开包含二维码的网页，并确保二维码位于当前可见区域
2. 通过以下任一方式触发识别：
   - 点击浏览器工具栏中的插件图标
   - 使用快捷键 `Ctrl+Shift+Q`（macOS 为 `Command+Shift+Q`）
   - 在网页图片上右键，选择“识别这张图片中的二维码”
3. 若使用工具栏图标或快捷键，插件会自动截图当前页面并打开结果页
4. 若使用图片右键菜单，插件会直接读取所选图片并打开结果页
5. 若识别成功，结果页会展示二维码内容；若内容是网址，可直接点击打开

## 使用说明与限制

- 页面截图识别适用于二维码位于当前可见区域的场景。
- 图片右键扫码适用于网页中的常规图片地址和 data URL 图片。
- 若图片使用 `blob:` 地址或浏览器限制了读取，结果页会提示改用页面截图识别。

## 快捷键修改

如需自定义快捷键，可打开 `chrome://extensions/shortcuts` 进行修改。
